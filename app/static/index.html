You will get a verdict, a probability, an evidence map for every face, and a PDF report you can share. Files are analyzed in memory and never stored.

How a file is checked

  1. Find the faces

    A lightweight face detector (YuNet) locates every face. For videos, up to 24 frames are sampled across the clip.

  2. Score with two detectors

    Two vision transformers, each trained on a different family of fakes, inspect every face crop.

  3. Fuse the evidence

    A fusion layer we fine-tuned on four public deepfake datasets combines both models into one probability.

  4. Show the reasoning

    Grad-CAM highlights the regions that pushed the decision, so you can judge the evidence yourself.

AUC measures how well the detector ranks fakes above real faces: 1.0 is perfect, 0.5 is a coin flip.

Know the limits

  • A result is a probability, not proof. Use it alongside other checks, such as the source of the file.
  • Heavy compression, tiny faces and new generation methods lower accuracy.
  • The detector judges faces. A real face placed into a fake scene will still read as real.
